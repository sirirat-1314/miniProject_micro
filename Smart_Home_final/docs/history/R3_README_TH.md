# 1.4 R3 — 7-segment และแบตหมด

แก้ในโฟลเดอร์ smart_home1.4_R2/smart_home1.4 ตามที่ระบุ

Firmware ID: SMART_HOME_V1.4_R3_20261006_SEG_EMPTY

1. แก้บิตน้ำหนัก 8 ของ BCD จาก PB9 เป็น PA9 ตาม Arduino D8 ของ NUCLEO-F411RE ในคู่มือ ST UM1724 (https://www.st.com/resource/en/user_manual/dm00105823.pdf) สกรีน D8/PB9 ของ shield ขัดกับ mapping บอร์ด จึงต้องยืนยันด้วยการทดสอบจอจริงอีกครั้ง ขาที่เหลือ PC7, PA8, PB10 คงเดิม
2. รายงาน GPIO อ่าน PA9 ให้ตรงกับขาที่ขับแล้ว ไม่ใช้การอ่าน PB9 เพื่อยืนยันเลข 8/9
3. เมื่อพลังงานหมด ล็อกโหลดและแสดงระดับ 0 จนชาร์จสะสมถึง EMPTY_RESTART_ENERGY=6000 units ใน project_config.h ป้องกันแสงเล็กน้อยทำให้กลับระดับ 1 ทันที ค่า energy/SOC ยังรายงานพลังงานจริง ระดับ 0 ในช่วงนี้หมายถึงยังไม่พร้อมจ่ายโหลด ไม่จำเป็นต้องมี energy เท่ากับ 0 ทุกขณะ
4. ไฟ ECO และ telemetry ECO ดับระหว่างล็อกแบตหมด เมื่อพลังงานฟื้นถึงเกณฑ์จะแสดง 1 และ ECO กลับมาติด โดยต้องสั่งเปิดโหลดใหม่
5. อนุญาต D test แม้แบตหมด ระหว่าง D จอแสดงเลขทดสอบแทนแบตและพักแบบจำลองพลังงานชั่วคราว

วิธีตรวจ: แฟลช Firmware/smart_home1.4.hex ใหม่ กด V ตรวจ ID ด้านบน กด D ดูเลข 0 ถึง 9 ครบวงจร หลังจบให้บังเซนเซอร์แสงจน Brightness ไม่เกิน 900 แล้วกด Z ต้องเห็น BAT=0, จอ 0 และ LED ทุกดวงดับ จากนั้นส่องแสงเพื่อสะสมพลังงานกลับถึง 6000 จึงกลับระดับ 1

การแก้เป็นการปรับโค้ดและ build ไม่ได้แฟลชบอร์ดให้อัตโนมัติ หากเลข 8/9 ยังผิดหลังตรวจ ID ถูกต้อง ต้องตรวจทางเดินสัญญาณ D8 ถึงขา BCD ของ decoder จริง ไม่ควรเปลี่ยนตารางตัวเลขเพื่อกลบปัญหาสายสัญญาณ
