# Smart Home 1.4 — เปิดอุปกรณ์กลับได้ใน ECO

สร้างจาก smart_home1.3_fixed แยกเป็นโครงการใหม่ ชื่อ firmware คือ `SMART_HOME_V1.4_20261005_ECO_REOPEN` ไม่มี OLED ตามรุ่นฐาน

## พฤติกรรมใหม่

| สถานะแบต | การทำงาน |
|---|---|
| NORMAL: 4–9 | ควบคุมอุปกรณ์ตามปกติ |
| เข้า ECO: 1–3 | ปิดแอร์และพัดลมหนึ่งครั้ง ล้างคำสั่งเปิดเก่า และเปลี่ยนแอร์เป็น Manual OFF ไฟยังทำงานตามโหมดเดิม |
| อยู่ใน ECO ต่อ | เปิดแอร์ พัดลม และไฟได้ ใช้พลังงานอัตราเดิม ไม่ปิดซ้ำทุก tick |
| EMPTY: 0 | ปิดทุกโหลด ล้างคำสั่งเก่า เปิดไม่ได้จนกว่าจะมีพลังงานกลับมา แล้วต้องสั่งเปิดใหม่ |

ตัวอย่าง: แบต 4 → 3 แอร์กับพัดลมดับ → กด A/F เปิดใหม่ → แบต 3 → 2 ยังทำงาน → แบต 0 ปิดทั้งหมด หากชาร์จกลับถึง 4 แล้วลดลง 3 อีกครั้ง จะปิดแอร์กับพัดลมอีกครั้ง

ยังมีสถานะพลังงานหลัก 3 สถานะ ไม่ได้เพิ่มสถานะหลักใหม่ แต่เปลี่ยนกติกาของ ECO

## ปุ่มใน Terminal

- A: สั่งแอร์แบบ Manual เปิด/ปิด
- F: เปิด/ปิดพัดลม
- L: เปลี่ยนไฟตามลำดับโหมดเดิม ดูแถว LIGHT ประกอบ
- M: สลับโหมดแอร์ Auto/Manual; Auto เปิดเมื่ออุณหภูมิที่อ่านได้ถูกต้องและสูงกว่า 30°C
- X: ปิดทั้งหมด
- ?: ขอข้อมูลล่าสุด, V: ตรวจ firmware, D: ทดสอบ 7-segment, Q: ปิด Terminal
- Z: ทำให้แบตจำลองหมด ใช้ทดสอบ EMPTY

หลังเข้า ECO ถ้าต้องการใช้แอร์ Auto อีกครั้งให้กด M; การบังคับกลับ Manual OFF ตอนเข้า ECO ป้องกัน Auto เปิดแอร์คืนทันทีโดยยังไม่ได้สั่ง

## พลังงาน

เป็นแบบจำลองพลังงานในโปรแกรม หน่วย units ไม่ใช่ค่ากระแสหรือความจุแบตจริง หนึ่ง tick = 100 ms

| โหลด | พลังงานต่อ tick |
|---|---|
| ไฟ | 100 |
| พัดลม | 150 |
| แอร์ | 200 + 8 × (30 − อุณหภูมิเป้าหมาย) |

เช่น เป้าหมาย 24°C แอร์ใช้ 248 units/tick เปิดทั้งสามอย่างใช้ 498 units/tick แม้อยู่ ECO สูตรไม่ลดลง แบตเต็ม 540000 units หนึ่งระดับ 60000 units

แสงไม่เกิน 900 ไม่ชาร์จ แสง 4095 ชาร์จสูงสุด 300 units/tick = 3000 units/s เมื่อปิดโหลดทั้งหมดใช้ประมาณ 20 วินาทีต่อระดับ หรือ 180 วินาทีจากศูนย์ถึงเต็ม หากเปิดโหลด การชาร์จสุทธิลดลงหรือแบตอาจลด

หากต้องการชาร์จช้าลง แก้ `SOLAR_MAX_PER_TICK` ใน `Inc/project_config.h` เช่น 300 → 150 จะใช้ประมาณ 40 วินาทีต่อระดับที่แสงสูงสุดและปิดโหลดทั้งหมด จากนั้น build และ flash ใหม่ หากแก้ค่านี้ควรแก้ข้อความช่วยเหลือ CHARGE ใน app_energy.c ให้ตรงด้วย

## โค้ดที่เปลี่ยน

1. `Application/Src/app_energy.c` / `EvaluateOutputs()` ตรวจ `eco_now && !s_state.power_saving` หมายถึงตอนนี้เป็น ECO แต่รอบก่อนยังไม่เป็น จึงสั่งปิดแอร์และพัดลมเพียงครั้งเดียว จากนั้นบันทึกสถานะใหม่ลง `power_saving`
2. เอาเงื่อนไขล็อก `!power_saving` ออกจากการกำหนด `ac_on` และ `fan_on` เพื่อให้คำสั่งใหม่เปิดได้ใน ECO ส่วนเงื่อนไข `energy == 0` ยังตรวจเป็นอันดับแรกและปิดทุกอย่าง
3. `UpdateEnergy()` ใช้สูตรเดิม จึงคิดพลังงานตามอุปกรณ์ที่เปิดจริงต่อไป การตรวจ outputs ก่อนและหลังอัปเดตพลังงานช่วยให้ตัดโหลดเมื่อข้ามระดับหรือแบตหมด
4. `PrintTelemetry()` ส่ง `POLICY=ECO_ENTRY_OFF_REOPEN_ALLOWED` และข้อความ ECO/EMPTY ให้ Terminal แยกกติกาถูกต้อง
5. `Inc/project_config.h` เปลี่ยน FIRMWARE_ID เป็น 1.4 และแก้คำอธิบายเวลาชาร์จให้ตรงค่าจริง ไม่เปลี่ยนอัตราชาร์จจากรุ่นฐาน
6. `live_status.ps1` เพิ่มค่าปรับหน้าตาด้านบนและข้อความ ECO ใหม่ ตรวจ POLICY จากบอร์ดจริง จึงไม่ใช้ชื่อหน้าจอมาตัดสินว่า firmware ได้อัปเดตแล้ว
7. เปลี่ยนชื่อ project/build/launch เป็น smart_home1.4 แยกจาก 1.3

ไดรเวอร์ 7-segment และการแปลงอุณหภูมิใช้เหมือนรุ่นฐาน การอ่าน GPIO ตรงกับคำสั่งไม่ได้ยืนยันว่าเลขบนจอจริงตรง ต้องดูจอประกอบ ส่วนอุณหภูมิยังระบุ ESTIMATED ตามแบบจำลอง NTC ของรุ่นฐาน

## Build และใช้งาน

เปิด PowerShell ในโฟลเดอร์ smart_home1.4 แล้วรัน:

```powershell
./build.ps1
./live_status.ps1 -SelfTest
```

ไฟล์ผลลัพธ์อยู่ `Firmware/smart_home1.4.elf` และ `.hex` ใน STM32CubeIDE ให้ Import Existing Project จากโฟลเดอร์นี้และเลือก project/launch smart_home1.4 ก่อน build หรือ debug อย่าเลือก launch ของ 1.3

หลัง flash firmware 1.4 แล้ว เปิด `Open_Live_Status.cmd` ในโฟลเดอร์นี้ หรือรัน `./live_status.ps1 -Port COM3` โดยใช้ COM ของบอร์ดจริงและปิดโปรแกรมอื่นที่จับพอร์ตอยู่ ตรวจแถว Firmware ว่าขึ้น `SMART_HOME_V1.4_20261005_ECO_REOPEN`

การสร้างรุ่นนี้ไม่ได้ flash ลงบอร์ดให้อัตโนมัติ

## การตรวจสอบ

ทดสอบ build firmware, parser/dashboard และโค้ด C จริงที่คอมไพล์เป็น ARM ผ่าน Unicorn โดยจำลองไดรเวอร์ รวม 28 checks ครอบคลุมเข้า ECO, เปิดกลับ, เข้า ECO ซ้ำ, ปุ่ม/UART, พลังงาน, EMPTY และชาร์จกลับ ไม่ใช่การทดสอบฮาร์ดแวร์จริง

หากต้องการรันทดสอบ ARM: ติดตั้ง Python และ toolchain STM32CubeIDE ใต้ C:/ST จากโฟลเดอร์นี้รัน `python -m pip install --target tests/.deps unicorn==2.1.4` แล้ว `python tests/run_energy_tests.py`

อ่านวิธีปรับ Terminal เพิ่มเติมใน `LIVE_STATUS_GUIDE_TH.md`
