# 1.4 R2 — 6 ตุลาคม 2026

รหัสที่ต้องเห็นในแถว Firmware: SMART_HOME_V1.4_R2_20261006_ECO_LDR

- จัดการการเข้า ECO ก่อนรับคำสั่งใหม่ เพื่อไม่ให้ล้างคำสั่งนั้นหลังจากกดปุ่ม
- คำสั่งปุ่มจริงและ A/L/F/M อัปเดตโหลดทันที ไม่ต้องรอ timer tick ถัดไป
- อยู่ ECO แบต 1–3 เปิดโหลดได้และคิดพลังงานตามเดิม แบตศูนย์ยังบล็อกโหลด
- PHOTO_ADC_BRIGHT_HIGH เปลี่ยนเป็น 0: ค่าแสงสำหรับควบคุม = 4095 − ADC เริ่มต้นเทียบเท่ารุ่นเดิมหลังจากกด I หนึ่งครั้ง ไม่ต้องกด I ทุกครั้งที่เปิดเครื่อง
- คำว่า LDR normal หมายถึงใช้ทิศเริ่มต้นที่กำหนดใน config; I ยังใช้สลับชั่วคราวได้

แฟลช Firmware/smart_home1.4.hex ของ R2 แล้วเปิด Live Status กด V ตรวจรหัสด้านบน การเปิด Terminal ใหม่อย่างเดียวไม่ได้อัปเดตโปรแกรมในบอร์ด

ทดสอบโดยรอแบต 1–3 กด A และ F: ต้องขึ้น ON และ Load เพิ่ม หากกด Z จะเป็นแบต 0 ซึ่งเปิดไม่ได้จนชาร์จกลับ ส่องแสงแล้ว Brightness ควรเพิ่ม บังแสงแล้วควรลด

พบสำเนาโครงการซ้อนใน smart_home1.4/smart_home1.4 จึงปรับไฟล์ที่แก้และ firmware ในทั้งสองชุดให้ตรงกัน แนะนำใช้โครงการระดับบนเพียงชุดเดียว
